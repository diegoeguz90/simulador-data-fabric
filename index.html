3.2. Decisión Arquitectónica: Integración Física (ETL) vs. Acceso Virtual

Una ventaja clave de Data Fabric es que no obliga a copiar todos los datos a un único almacén físico. Combina Integración Física (ETL/ELT) para históricos pesados con Virtualización de Datos / APIs para datos en tiempo real o altamente sensibles:

Fuente Naturaleza y Latencia Mecanismo Seleccionado Justificación Técnica y de Gobierno
F1_OPS (SIIV Operaciones) Alto volumen histórico de vuelos diarios Ideal consolidar físicamente en lote diario con deduplicación (DQ-01) para no sobrecargar la base de datos operativa de planes de vuelo.
F2_MET (METEO-AERO) Flujo horario cambiante (Alertas METAR en vivo) El estado meteorológico cambia cada hora; el acceso virtual vía conector API permite consultar la alerta vigente sin esperar procesos batch nocturnos.
F3_SMS (SIGSO Incidentes MOR) Alta reserva legal (Anexo 19 OACI / Cultura Justa) La virtualización gobernada permite exponer el conteo y severidad del incidente aplicando enmascaramiento dinámico sobre la cédula del reportante sin duplicar datos sensibles fuera de la Secretaría SMS.
F4_FIN (RECAUDO-AERO) Cierres contables auditables y conciliación Para reportes oficiales de recaudo se requiere una foto física certificada (tras aplicar DQ-05 para excluir vuelos cancelados) que garantice reproducibilidad ante Contraloría.
